# Классификация съедобности грибов

Этот проект предназначен для автоматической классификации грибов на «съедобные» (edible) и «ядовитые» (poisonous) с использованием алгоритмов машинного обучения: Naive Bayes и Random Forest.

## Как использовать

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение Python:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск классификации
Для выполнения полного цикла (анализ данных, предобработка, обучение и оценка) запустите основной скрипт:

```bash
python3 main.py
```

### 3. Результаты работы
После запуска скрипт создаст следующие файлы в директории проекта:

*   **Графики анализа (EDA):**
    *   `target_distribution.png` — баланс классов (сколько съедобных и ядовитых).
    *   `features_distribution.png` — распределение признаков (запах и цвет шляпки).
*   **Оценка моделей:**
    *   `confusion_matrix_naive_bayes.png` — матрица ошибок для Naive Bayes.
    *   `confusion_matrix_random_forest.png` — матрица ошибок для Random Forest.
    *   `roc_curve.png` — ROC-кривая для сравнения точности моделей.
*   **Консольный вывод:** Итоговая таблица с метриками (Accuracy, Precision, Recall, F1).

## Структура данных
Скрипт ожидает файл `mushroom_data.csv` со следующими ключевыми колонками:
*   `Mushroom_quality`: целевая переменная (`e` - съедобный, `p` - ядовитый).
*   Признаки: `cap_shape`, `cap_color`, `odor`, `stalk_root` и другие.

## Особенности
*   **Обработка пропусков:** Значения `?` в колонке `stalk_root` автоматически заменяются на `Unknown`.
*   **Безопасность:** Особое внимание уделено метрике **Recall** для ядовитых грибов — это критически важно, чтобы минимизировать риск пропуска ядовитого гриба.
